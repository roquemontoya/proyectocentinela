- PWA (Aplicación Web Progresiva):
  - Cómo funciona: Es una aplicación web que se comporta como una app nativa, puede funcionar offline, permite instalación en dispositivos, y es accesible vía navegador.
  - Relaciones: Integra frontend (HTML/CSS/JS), backend (en este caso Supabase), y servicios (Vercel para despliegues).
  - Estado actual: Centinela es una PWA con módulos de inspección, mapas, reportes, y autenticación vía Supabase.

- Contexto del Proyecto Centinela:
  - Objetivo: Gestión de inspecciones y control de seguridad industrial (extintores, hidrantes, etc.).
  - Datos clave: CSV inicial de extintores (1400+ registros), integrados en Supabase.
  - Dos ramas: `main` (producción) y `easter-egg-startrek` (tema visual LCARS).
  - Importante: Mantener siempre integridad de permisos (RLS) y seguridad en Supabase.
