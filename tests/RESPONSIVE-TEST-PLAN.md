# Matriz de pruebas responsive

Oculus y Centinela deben inspeccionarse en anchos CSS de 320, 360, 375, 390, 414, 430, 600, 768, 800, 820, 912, 1024, 1280, 1366, 1440, 1600 y 1920 px.

Para cada ancho comprobar desbordamiento horizontal, texto y botones cortados, navegación, tarjetas y formularios. Capturar 320, 390, 768, 1024, 1366 y 1920 px.

La maqueta Oculus no sustituye pruebas de la aplicación real autenticada ni validaciones de RLS/Supabase.
